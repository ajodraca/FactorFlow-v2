# Trust and Not-Found Journeys End to End

## User Story

As an owner-operator, I want capability flow 2 proven against the real product, so that a partial download yields a *Mostly yes* verdict with named rows, **Download now** starts a full download whose end refreshes the checks, and an unrecognised symbol can be stopped with its history kept or replaced.

## Description

Logical component: `data-health-ui`. Creates `tests/e2e/data-health-trust.spec.ts` and `tests/e2e/data-health-not-found.spec.ts` with the two journeys of `component-design-data-health-ui.md` §7 against a real API and PostgreSQL container, using the delivered acquisition stack stub: (1) a partial download: verdict *Mostly yes*, rows named, **Download now** starts a full download that heads Recent downloads with its progress, and the checks refresh at its end; (2) an unrecognised symbol's row: **Stop following** confirmed and the row leaves with its history still on Coverage; **Follow a different symbol** lands on Followed stocks with the add field focused. The journeys cross into Coverage and Followed stocks (E7), hence the dependencies on a later epic (DEC-0223).

Breakdown and ordering: DEC-0223.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-11] Data health MUST open with a one-sentence verdict naming how many followed stocks need attention.
- [AC-13] Each row MUST name the stock, what was being downloaded, the reason and the consequence, and offer the fix that applies.
- [AC-14] A stock the provider does not recognise MUST offer stopping following and following a different symbol, never a download.
- [AC-15] **Download now** MUST start a download over the whole followed list.
- [AC-21] Before any download has ended, Data health MUST state that no data has been downloaded yet.

### Derived

- [DAC-E6-S6-1] Given an empty install, When `/data` opens, Then the card reads *No data has been downloaded yet.*; given a download that ended `partial` with failures on three stocks, When `/data` opens, Then the verdict reads *Mostly yes. 3 of {m} followed stocks need attention; ...* and *Needs fixing · 3* lists them. (traces to: AC-21, AC-11, AC-13)
- [DAC-E6-S6-2] Given **Download now** activated, When the stub runs the download, Then a `progressbar` heads Recent downloads within one attention tick, and when it ends the Daily prices card's result line changes without a reload. (traces to: AC-15)
- [DAC-E6-S6-3] Given a *Not found* row for *FBXX*, When **Stop following FBXX** is confirmed by keyboard, Then the row leaves, the polite region announces *Stopped following FBXX*, and `/data/coverage?symbol=FBXX` still shows the stock as *Stopped following* with its coverage. (traces to: AC-14)
- [DAC-E6-S6-4] Given **Follow a different symbol than FBXX** followed, When `/data/followed` opens, Then `document.activeElement` is the field named *Symbol of the stock to follow*. (traces to: AC-14)
