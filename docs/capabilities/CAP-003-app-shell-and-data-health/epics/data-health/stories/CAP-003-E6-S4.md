# Recent Downloads and What You Follow

## User Story
As an owner-operator, I want the five most recent downloads with a running one's progress at their head, and a summary of what I follow, so that Data health shows the state of the whole download side in one place.

## Description
Creates `web/src/screens/data-health/recent-downloads.tsx` (`card` *Recent downloads*, a `data-table` `compact` with `history` semantics over `listAcquisitionRuns({ limit: 5 })`: *Started* as row header linking to `/data/downloads/{id}`, *Outcome* through `StatusBadge`, *Ended* or an em dash while running, *Result* per data-health-ui 2.6 with the *Partial* and *Interrupted* sentences; a running download heading the list with `progress` `determinate` *{done} of {total} stocks* from attention's `latest_download.progress`; re-read on each attention answer while `latest_download` is non-terminal and otherwise only on load; *checked {time}* in the header both while a download runs and otherwise) and `what-you-follow.tsx` (`card` `summary`: *Followed stocks {active_count}*, *Stopped following {retired_count} (history kept)*, *History depth {y} years* or *not set* as a link to `/settings`, *Market data key* `badge` *Found* / *Missing* / `coverage-unknown` *Not determinable* from `health.credential_present`, **Manage followed stocks**). Each card's failed read keeps its header and renders *Couldn't read {recent downloads / what you follow}: {reason}.* with **Try again**. Writes `recent-downloads.test.tsx` and `what-you-follow.test.tsx`.

Source: component-design-data-health-ui.md 2.1, 2.6, 7; epic CAP-003-E6 DAC-E6-14, DAC-E6-16, DAC-E6-17.
