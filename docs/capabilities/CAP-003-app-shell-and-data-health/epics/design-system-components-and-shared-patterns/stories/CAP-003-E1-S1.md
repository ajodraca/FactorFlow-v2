# Vendoring Foundation: cn, Tailwind Token Keys, badge, button, card and the AC-26 Literal Scan

## User Story
As an owner-operator, I want the first design-system components vendored as first-party code bound to the theme tokens, so that every surface this capability builds is assembled from the same components and no surface carries a literal of its own.

## Description
Creates `web/src/components/ui/utils.ts` (`cn()`: `clsx` + `tailwind-merge`, as shadcn/ui ships it) and vendors `badge` (`status-<tier>`, `coverage-present`, `coverage-absent`, `coverage-unknown`, `secondary`), `button` (`default`, `secondary`, `outline`, `ghost`, `blocked`, `asChild` for links) and `card` (`default`, `metric`, `summary`) into `web/src/components/ui/`, copied as shadcn/ui ships them with `@/` imports rewritten to relative paths and no `tsconfig.json` or `vite.config.ts` alias (ui-components 2.1; DEC-0211). Extends the delivered `tailwind.config.js` with the colour and radius keys of DAC-E1-11, each in the delivered `hsl(var(--token) / <alpha-value>)` form resolving to a token `theme.css` already defines, adding no token (ui-components 2.2). Adds the packages these three components need, `clsx`, `tailwind-merge`, `class-variance-authority`, `lucide-react` and `@radix-ui/react-slot`, each with its licence recorded (tech stack v7 OQ-TS-10; SEC-DEP-003).

Writes the AC-26 literal-scan test, `web/src/components/token-literals.test.ts`, the automated check DEC-0223 answer A names for DAC-E1-12 and DAC-E3-16 (backlog review v3 FINDING-5): it reads every `.ts` and `.tsx` source under an exported list of scanned directories, starting with `web/src/components/`, and fails on any spacing, size or colour literal. Later stories widen the list (E3 for `web/src/app/`, each screen story for its directory). Widens the delivered `web/src/api/render.test.tsx` glob to `web/src/components/` (ui-components 4, 7).

Source: component-design-ui-components.md 2.1, 2.2, 3, 4, 7; epic CAP-003-E1 NFR *Tokens only*, *Security*.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-26] Every surface MUST be built from the product's design-system components and consume its theme tokens, with no spacing, size or colour literal outside the theme.
- [AC-25] Every operation MUST be completable by keyboard. This story delivers the `button` `blocked` contract every gated action relies on.
- [DAC-E1-11] `tailwind.config.js` MUST gain only the keys the vendored components reference, each resolving to a token `theme.css` already defines; the delivered `web/src/app/shell.tokens.test.tsx` MUST keep passing. (traces to: AC-26)
- [DAC-E1-12] No vendored component or pattern MUST contain a spacing, size or colour literal outside the theme, and no `package.json` dependency MUST be added beyond the ten packages tech stack v7 confirms and the `@radix-ui/react-*` primitives, each with its licence recorded when added. (traces to: AC-26)

### Derived
- [DAC-E1-S1-1] Given the three vendored sources, When they are copied, Then every `@/` import is rewritten to a relative path, `tsconfig.json` and `vite.config.ts` gain no alias, and `npm run lint` passes on them as first-party code. (traces to: AC-26)
- [DAC-E1-S1-2] Given `web/src/components/token-literals.test.ts`, When it runs over `web/src/components/`, Then it fails on any `\b\d+(\.\d+)?(px|rem|em|vh|vw)\b`, `#[0-9a-fA-F]{3,8}\b`, `rgb(` or `hsl(` literal in a non-test `.ts` or `.tsx` source, allowing only `0`, the vendored `command` dialog's 560 px width (shadcn/ui's own, UX design 1.1; epic E1 NFR) and `web/src/app/layout.ts`, and it exports the scanned-directory list for later stories to widen. (traces to: AC-26)
- [DAC-E1-S1-3] Given `button` `blocked`, When rendered with a reason, Then it stays focusable, is `aria-disabled`, exposes the reason through `aria-describedby` and fires no handler on activation; `button` `disabled` is not used where a precondition gates an action. (traces to: DAC-E1-14, DAC-E1-15)
- [DAC-E1-S1-4] Given `badge`, When each `status-<tier>` and `coverage-*` variant renders, Then its colour resolves to the `--status-*` or `--coverage-*` token through the new Tailwind keys and `shell.tokens.test.tsx` still passes. (traces to: AC-26)
- [DAC-E1-S1-5] Given `package.json`, When the five packages are added, Then each carries its licence in the change and no other package is added; `web/src/api/render.test.tsx` passes with its glob widened to `web/src/components/`. (traces to: DAC-E1-12)

## Technical Details

- None: this story serves no endpoint and consumes none beyond the shell context.

- TypeScript, React 18, Tailwind bound to `design-system/theme.css` (tech stack v7).
