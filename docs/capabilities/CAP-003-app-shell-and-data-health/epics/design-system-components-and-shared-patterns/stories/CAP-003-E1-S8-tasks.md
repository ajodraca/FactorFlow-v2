# Tasks: CAP-003-E1-S8 — Needs You Derivation and Sort: needs-you.ts and the Item Row

**Story**: `repos/factorflow-v2/FactorFlow-v2/docs/capabilities/CAP-003-app-shell-and-data-health/epics/design-system-components-and-shared-patterns/stories/CAP-003-E1-S8.md`

## Summary

Creates `web/src/components/patterns/needs-you.ts`, the one place the *Needs you* list is derived and ordered (component design `ui-components` 2.6; DEC-0203, DEC-0216, both upheld), so Home's list and the rail's Home chip are the same array (AC-9, AC-16). It exports `NeedsYouKind` (re-exported from CAP-003-E1-S5's `tiers.ts`), `NeedsYouItem { kind, tier, recordedAt, target, runId? }`, `deriveNeedsYou(attention, scores)` and `sortAttention(items)`. `deriveNeedsYou` maps the three server items of `attention.items` one to one, composes `first_download`, `first_scores` and `score_failed` from the served summary (and `first_download` under a `404` summary only while `latest_terminal_download` is null, AC-7), takes every tier from `tierOf` and returns no user-visible string. `sortAttention` orders by CAP-003-E1-S7's `TIER_ORDER` then `recordedAt` newest first, stably. It also creates `web/src/components/patterns/needs-you-item.tsx`, the blueprint §4.1 row `home-ui` fills with its copy: an `aria-hidden` severity tile in the tier's colour pair and shape, the tag badge through `StatusBadge` with `labelOf`'s tag, a title, a body and exactly one link styled `button` `outline` to the item's `target` (DAC-E1-S8-3). `Attention` and `ScoreState` are imported as types only from CAP-003-E3-S1's `web/src/app/shell-types.ts` (the deliberate later-epic edge, DEC-0223 answer A, DEC-0227). Pure functions and one presentational component; no endpoint, schema or storage.
