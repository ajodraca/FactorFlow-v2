### IR-001 — TC-COMP-003 does not pin which token each Tailwind key names, nor the set of scales extended

- **Severity**: HIGH
- **Scope**: initial
- **Status**: OPEN
- **Acceptance criteria**: DAC-E1-11, AC-26
- **Tasks**: T002 (T010)
- **Files**: `web/src/components/token-literals.test.ts:83-106` (checks (c) and (d)); `tailwind.config.js:34-54`
- **Claim challenged**: TC-COMP-003 proves "only the listed keys are added, each resolving to a token `theme.css` already defines", and fails naming any key that names an undefined token.
- **Observed evidence**: Check (c) accepts any `--name` in the right shape, and (d) accepts any declared token. Mutants `tailwind.config.js:manual:review-1` (`primary` bound to `--secondary`) and `:review-2` (`status-foreground` bound to `--foreground`) survive. Check (d) reads only `colors`, `borderRadius`, `ringWidth` and `backgroundImage`, and nothing pins the set of `theme.extend` scales. `:review-3`, a new `boxShadow: { DEFAULT: "var(--shadow)" }` that is an unlisted key naming an undeclared token, also survives. The delivered `shell.tokens.test.tsx` reads only `spacing`, `fontSize` and `height`.
- **Expected evidence/behavior**: T010 binds each added key as `hsl(var(--<same name>) / <alpha-value>)`, and button spec section 6 puts the primary background on `--primary`. DAC-E1-11 says the config gains *only* the listed keys. TC-COMP-003's edge case says the test fails naming any key that names an undefined token.
- **Impact**: A later edit could rebind a vendored colour to the wrong token: every default button would render on the secondary surface, and status text would turn from white to near-black. It could also add an unreviewed scale bound to a token that does not exist. Either change would pass the AC-26 check this story establishes, and the suite would stay green.
- **Required remediation**: Make the three surviving mutants fail. Pin every colour key to its same-named token, and make an unlisted key, or a `var()` naming an undeclared token, in any `theme.extend` scale fail with its name.
