# Take Over as-of-line.tsx from CAP-002 and Generalise It to AsOfLine

## User Story
As an owner-operator, I want the as-of line built once, so that Home, Data health and Research show their freshness the same way.

## Description
Takes over CAP-002's `web/src/components/patterns/as-of-line.tsx`, delivered specialised to the Research as-of line (DEC-0073), and generalises it to `AsOfLine` (parts joined by *·* at `--text-xs` `--muted-foreground`), with CAP-002's Research line composing `AsOfLine` and rendering what it rendered before, so CAP-002's `as-of-line.test.tsx` cases for that line keep passing (ui-components 2.1; DAC-E1-13; owner decision 2026-10-25, review v1 FINDING-14). It is the one delivered pattern file this epic edits rather than creates.

**Sequencing.** The owner fixed the order, CAP-002 lands first (capability OQ-2). This clone does not yet hold the file (backlog review v3, *Repository facts*), so this story is scheduled after CAP-002's `classification-ui` has merged; nothing else in E1 waits on it (epic CAP-003-E1 Open Questions).

Source: component-design-ui-components.md 2.1, 7; epic CAP-003-E1 DAC-E1-13.
