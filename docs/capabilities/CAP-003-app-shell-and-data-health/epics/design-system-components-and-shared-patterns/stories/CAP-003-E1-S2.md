# Vendor the Form Family: form, input, textarea, checkbox, radio-group and select

## User Story
As an owner-operator, I want the form controls setup, Settings and the followed-stocks screen use vendored once with their keyboard contracts, so that every field, choice and list on the owner interface behaves the same way.

## Description
Vendors `form` (`stacked`, `inline`, on `react-hook-form` with the `zod` resolver), `input` (`text`, `numeric` with suffix), `textarea` (`list`), `checkbox` (`default`), `radio-group` (`cards`, Radix) and `select` (`inline`, Radix) into `web/src/components/ui/` as shadcn/ui ships them, with contract tests per component (ui-components 2.1, 7). Adds `react-hook-form`, `zod`, `@hookform/resolvers`, `@radix-ui/react-label`, `@radix-ui/react-radio-group`, `@radix-ui/react-checkbox` and `@radix-ui/react-select`, each with its licence (DEC-0215; SEC-DEP-003). Consumers: setup (E4) for the years field, the source radio group and the pasted list; Settings and Followed stocks (E7) for the depth form, the add field and the filters.

Source: component-design-ui-components.md 2.1, 3, 7; UX design §3 component mapping.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-26] Every surface MUST be built from the product's design-system components and consume its theme tokens.
- [AC-25] Every operation MUST be completable by keyboard; Radix supplies the radio, select and checkbox keyboard contracts.
- [DAC-E1-12] No vendored component MUST contain a spacing, size or colour literal outside the theme, and no dependency MUST be added beyond the confirmed packages and the Radix primitives, each with its licence. (traces to: AC-26)

### Derived
- [DAC-E1-S2-1] Given `radio-group` `cards`, When focused, Then the group is one tab stop and arrow keys move the selection; `select` `inline` opens and closes from the keyboard and exposes `combobox` and `listbox` roles; `checkbox` toggles on Space. (traces to: AC-25)
- [DAC-E1-S2-2] Given `input` `numeric` with a suffix, When rendered, Then the suffix is part of the input's accessible name, and a `form` field error is linked to its control through `aria-describedby` and announced. (traces to: AC-25)
- [DAC-E1-S2-3] Given the six components, When `token-literals.test.ts` runs, Then it passes over them, and `package.json` gains only the seven packages above with their licences. (traces to: DAC-E1-12)
