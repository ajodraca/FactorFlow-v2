# Presence Renderings and the America/Chicago Formatters

## User Story
As an owner-operator, I want absent, not determinable and present values told apart on every screen and every time shown in America/Chicago with its zone, so that nothing undetermined is ever shown as a value.

## Description
Creates `web/src/components/patterns/presence.tsx` (`Absent`: an em dash in `--value-missing` with visually hidden text naming what is absent; `NotDeterminable`: `badge` `coverage-unknown` with *Not determinable* or a caller's label, `--pattern-indeterminate` and its reason) and `web/src/components/patterns/format.ts` (`formatInstant(date, { seconds })`, `formatClock`, `formatSessionDate`, `formatCount`, `formatDownloadName`) per ui-components 2.5 and DAC-E1-8, DAC-E1-9. `formatInstant` builds `YYYY-MM-DD HH:MM zone` from `Intl.DateTimeFormat` parts with `timeZoneName: "short"` in `en-US`, never a locale format; the delivered `formatTimestamp` in the shell's health module is kept for the delivered tests (system design assumption 5). `formatDownloadName` renders *Download {YYYY-MM-DD HH:MM zone}* from `started_at`, else `requested_at`, the naming the owner confirmed permanent (capability OQ-1).

Source: component-design-ui-components.md 2.5, 7; STD-UI-3, STD-UI-4, STD-UI-5, STD-UI-14.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-24] Every data-bearing region MUST NOT collapse never-populated into nothing-found and MUST keep present, absent and not determinable apart. This story delivers the presence renderings.
- [AC-25] Every polled region MUST show its last-updated time: this story delivers `formatClock` for *checked {time}*.
- [DAC-E1-8] `Absent` MUST render an em dash with hidden text, never `0` and never blank; `NotDeterminable` MUST render `badge` `coverage-unknown` with its reason, never a dimmed absent and never a passed check. (traces to: AC-24, AC-8)
- [DAC-E1-9] `formatInstant`, `formatClock`, `formatSessionDate`, `formatCount` and `formatDownloadName` MUST render as DAC-E1-9 states, in America/Chicago with *CDT* or *CST*. (traces to: AC-25)

### Derived
- [DAC-E1-S6-1] Given an instant in October and one in January, When `formatInstant` renders them, Then the zones are *CDT* and *CST* respectively, the seconds appear only with `{ seconds: true }`, and a `2026-03-08` session date renders unshifted through `formatSessionDate`. (traces to: DAC-E1-9)
- [DAC-E1-S6-2] Given `formatCount(1236)`, When rendered, Then it reads *1,236*; given a download with `started_at` null, When `formatDownloadName` renders it, Then it uses `requested_at`. (traces to: DAC-E1-9)
- [DAC-E1-S6-3] Given `NotDeterminable` with a reason, When rendered, Then the reason is in its accessible description and its badge is `coverage-unknown`, never `status-good`. (traces to: DAC-E1-8)
