# data-health-api Integration Tests Through the Delivered Application

## User Story
As an owner-operator, I want the three routes proven against a real store through the real application, so that the counts the interface shows are the counts the store holds.

## Description
Writes `data-health-api`'s two integration test files of data-health-api 2.1 and 7, `tests/integration/test_api_data_health.py` (attention and data-health bodies match the reader's values on a seeded PostgreSQL; `affected_count` equals the row count; keyset pages concatenate to the full problem set; an empty store answers `200` with `never_acquired` true and both checks `null`; a reader raising `psycopg.Error` yields the delivered `500 internal_error` envelope with `X-Request-Id`) and `tests/integration/test_api_data_health_host_origin.py` (a foreign `Host` gets `400 host_not_allowed` on all three routes; a foreign `Origin` on a `GET` is not refused). These run through `create_app`, so they follow the `ingestion-api` registration story rather than being written by it (backlog review v2 FINDING-9).

Source: component-design-data-health-api.md 2.1, 2.2, 7; component-design-ingestion-api.md 7; epic CAP-003-E2 DAC-E2-9, DAC-E2-10.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-13] `affected_count` MUST equal the number of *Needs fixing* rows.
- [AC-16] `problems.stock_count` and the rows MUST be the same set.
- [AC-21] An empty store MUST answer `200` with both checks `null`.
- [DAC-E2-9] The three routes MUST answer `200` with the §4.2 shapes whenever the database answers; a `psycopg.Error` MUST propagate to the delivered `500` `internal_error` envelope with `X-Request-Id`. (traces to: AC-21, AC-11)
- [DAC-E2-10] A foreign `Host` MUST get `400 host_not_allowed` on all three routes and a foreign `Origin` on a `GET` MUST NOT be refused. (traces to: AC-17, AC-16)

### Derived
- [DAC-E2-S6-1] Given a seeded store with failures on three stocks, When `GET /api/data-health/problems` is paged with `limit=2`, Then the concatenated rows equal the reader's full problem set and the last page carries no cursor. (traces to: DAC-E2-3)
- [DAC-E2-S6-2] Given the `500` case, When asserted, Then the body is the delivered envelope's fixed message with no internal detail (SEC-ERR-001) and the `X-Request-Id` header is present. (traces to: DAC-E2-9)
