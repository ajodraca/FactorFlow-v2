# Router Registration on the Delivered Application and the No-Secrets Extension

## User Story

As an owner-operator, I want the three new routes served by the application the product already runs, so that they sit behind the same loopback, Host and request-id rules as every delivered route and never return the market data key.

## Description

Logical component: `ingestion-api`. Makes the two delivered-file edits `component-design-ingestion-api.md` §2.1 assigns to it (DEC-0211, PROVISIONAL): `src/factorflow/api/app.py` gains the `data_health` import and one `app.include_router(data_health.router)` line with the delivered routers, before `_add_static_mount`, after `classification-api`'s two calls if they have landed (§2.2); `tests/unit/test_api_no_secrets.py` gains the parametrised test of §2.3 with its `stub_reader_functions` and `StubPool` helpers, proving a populated `200` body of each route never contains `FACTORFLOW_MASSIVE_API_KEY`'s value. Carries `data-health-api`'s integration tests, which prove registration through `create_app`: `tests/integration/test_api_data_health.py` and `tests/integration/test_api_data_health_host_origin.py` (`component-design-data-health-api.md` §7). `_resource_for_path` is not extended (§3; E2 open question 2).

Breakdown and ordering: DEC-0223.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-4] No new response MUST carry the market data credential's value; the delivered no-secrets test is extended to the three new routes.
- [AC-17] No delivered request or response model, route, status code or refusal MUST change.
- [AC-16] `problems.stock_count` on the attention read MUST be the same set as the *Needs fixing* rows.
- [DAC-E2-10] The router MUST be included by `create_app` with the delivered routers and before `_add_static_mount`, so a foreign `Host` gets `400 host_not_allowed` on all three routes, a foreign `Origin` on a `GET` is not refused, an unknown `/api` path still answers the `not_found` envelope, and every refusal carries a request id. (traces to: AC-17, AC-16)
- [DAC-E2-13] The delivered `tests/unit/test_api_no_secrets.py` MUST gain one parametrised test proving a populated `200` body of each of the three routes never contains the value of `FACTORFLOW_MASSIVE_API_KEY`. (traces to: AC-4)

### Derived

- [DAC-E2-S5-1] Given `create_app()` and a seeded PostgreSQL, When the three paths are requested with a loopback `Host`, Then each answers `200` through the delivered application, not the `not_found` envelope, and the attention and data-health bodies equal the reader's values. - [DAC-E2-S5-4] Given `Host: example.com`, When each route is requested, Then it answers `400 host_not_allowed` with `X-Request-Id`; given a foreign `Origin` on a `GET`, Then it is not refused. (traces to: DAC-E2-10)
