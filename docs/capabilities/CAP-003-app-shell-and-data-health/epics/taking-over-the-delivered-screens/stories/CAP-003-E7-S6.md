# The Vocabulary Sweep over the Five Screens and the requestJson Export Check

## User Story
As an owner-operator, I want one test that renders every taken-over screen in every state and rejects any domain term, so that a relabel can never regress silently.

## Description
Writes `web/src/screens/vocabulary.test.tsx` (owner-web-app 2.1, 7; DAC-E7-3): renders each of the five screens in its populated, empty, error and dialog states and asserts none of *instrument*, *acquisition*, *acquire*, *run*, *runs*, *Retire*, *Retired*, *Provider credential* appears as a whole word, in any case, in visible text or accessible names. Also carries DAC-E7-12's second clause as a check: `web/src/api/client.ts` exports `requestJson` (added by CAP-003-E3-S1 under DEC-0223, or by CAP-002-E4-S1), and `web/src/api/client.coverage.test.ts`, `client.runs.test.ts` and `render.test.tsx` are unchanged by E7.

Source: component-design-owner-web-app.md 2.1, 2.6, 7; epic CAP-003-E7 DAC-E7-3, DAC-E7-12, DAC-E7-13.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-19] Every user-visible label on the five screens MUST use the display label STD-UI-1 defines and MUST NOT show the domain term beside it.
- [AC-17] `web/src/api/client.ts` MUST export `requestJson`; the delivered client tests are unchanged.
- [DAC-E7-3] A vocabulary sweep test MUST render each of the five screens in its populated, empty, error and dialog states and assert none of the eight terms appears as a whole word, in any case, in visible text or accessible names. (traces to: AC-19)
- [DAC-E7-12] `web/src/api/client.ts` MUST export `requestJson` unless CAP-002 has already added the export; the export itself is CAP-003-E3-S1's, this story confirms it. (traces to: AC-17)
- [DAC-E7-13] The screen directories MUST keep their delivered names and `web/src/api/types.ts` MUST NOT be edited. (traces to: AC-19)

### Derived
- [DAC-E7-S6-1] Given the sweep, When a screen's `copy.ts` is changed to include *Retired*, Then the test fails naming the screen, the state and the term, so the assertion is proven live. (traces to: DAC-E7-3)
- [DAC-E7-S6-2] Given the sweep's matcher, When it runs, Then it reads both `textContent` and every element's computed accessible name (Testing Library's `getByRole` name queries), and matches whole words case-insensitively so *running* and *Coverage* pass. (traces to: DAC-E7-3)
- [DAC-E7-S6-3] Given `web/src/api/client.ts`, When the test imports `{ requestJson }` from it, Then the import type-checks and `web/src/api/types.ts` and the `instruments` and `runs` directory names are unchanged from `HEAD` before E7. (traces to: DAC-E7-12, DAC-E7-13)
