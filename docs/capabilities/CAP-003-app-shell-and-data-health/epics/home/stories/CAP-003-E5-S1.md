# Home Header, Market State and the Home Copy Catalogue

## User Story
As an owner-operator, I want Home to open with today's date, the market state and how current prices are, so that I know in one line what the rest of the screen is as of.

## Description
Creates `web/src/screens/home/header.tsx` (`h1` *{Weekday}, {YYYY-MM-DD}* in America/Chicago, the weekday in English, DEC-0209; the `AsOfLine` *{market state} · prices current to {prices_as_of} · checked {time}*), `web/src/screens/home/market-state.ts` (`marketState(now)`: `closed` on Saturdays, Sundays and weekdays before 08:30 or from 15:00 America/Chicago, `not_determinable` inside weekday 08:30 to 15:00, DEC-0206, recomputed each minute with no read) and `web/src/screens/home/copy.ts` (the item titles, bodies and actions of home-ui 2.5 and every other string of UX design 1.3). `closed` renders *Market closed*; `not_determinable` renders `badge` `coverage-unknown` *Market state not determinable* with the hidden text *FactorFlow has no trading calendar, so it can't tell a session from a holiday.*; `prices_as_of` renders as a session date or *prices not downloaded yet* when null, an em dash with *not determinable* while attention fails. Writes `header.test.tsx` and `market-state.test.ts`.

Source: component-design-home-ui.md 2.1, 2.3, 3, 7; epic CAP-003-E5 DAC-E5-6; DEC-0206, DEC-0209.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-24] The market state inside session hours MUST render as not determinable, never as open.
- [AC-25] The as-of line MUST show *checked {time}* from the attention read.
- [AC-26] Home MUST be built from `ui-components` and consume theme tokens only.
- [DAC-E5-6] The header MUST render the date and the market state as stated, across a DST change. (traces to: AC-24)

### Derived
- [DAC-E5-S1-1] Given a Saturday, a Sunday, a weekday 08:29 and a weekday 15:00 in America/Chicago, When `marketState` runs, Then each is `closed`; given a weekday 08:30 and 14:59, Then `not_determinable`, with the same results across the March and November DST changes. (traces to: DAC-E5-6)
- [DAC-E5-S1-2] Given `header.tsx` on 2026-10-15, When rendered, Then the `h1` reads *Thursday, 2026-10-15*, and `prices_as_of` renders unshifted through `formatSessionDate`. (traces to: DAC-E5-6)
- [DAC-E5-S1-3] Given the header, its as-of line and the copy catalogue rendered in every state this story defines, When its visible text and accessible names are scanned for *instrument*, *acquisition*, *acquire*, *run*, *runs*, *Retire*, *Retired*, *Provider credential* as whole words in any case (the DAC-E7-3 term list), Then none appears, and every label is the STD-UI-1 v6 display label from `labelOf` or this component's `copy.ts`, never the domain term beside it. (traces to: AC-19)
- [DAC-E5-S1-4] Given the market-state badge (`coverage-unknown` through `NotDeterminable`), When rendered, Then each goes through `StatusBadge` with its label as text and its tier shape `aria-hidden`, a value no artifact can determine goes through `NotDeterminable`, and no state is conveyed by colour alone. (traces to: AC-20)
