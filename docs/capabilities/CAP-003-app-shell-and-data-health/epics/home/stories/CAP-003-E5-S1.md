# Home Screen Scaffold: Header, Market State and the Honest Empty State

## User Story

As an owner-operator, I want Home to open with today's date and the market state and, before any download, to say plainly that no data has been downloaded and offer setup, so that the first screen never shows empty checks as if they passed.

## Description

Logical component: `home-ui`. Creates `web/src/screens/home/index.tsx` (`HomeScreen`: header, a three-column summary row with the tile's slot in the first column and the other two empty, the *Needs you* slot, and the empty state), `header.tsx`, `market-state.ts` and `copy.ts`, as `component-design-home-ui.md` §2.1 to §2.3 specify. The `h1` is *{Weekday}, {YYYY-MM-DD}* in America/Chicago (DEC-0209); the as-of line is E1-S6's `AsOfLine` with *{market state} · prices current to {prices_as_of} · checked {time}*; `marketState(now)` is DEC-0206's rule, recomputed each minute with no read. While `attention.latest_download` is null the screen renders the never-downloaded card with **Start setup**; the tile (E5-S2) and the card (E5-S3) fill their slots in later stories. Each card's error state keeps its header and renders the three-part error with **Try again** through `StateRegion`. Home never reads `GET /api/data-health` (DEC-0219 withdrawn). The `/home` route is registered by E3-S8.

Carries AC-19 and AC-20 for this screen (review v1 FINDING-4): every string lives in `copy.ts` in the display vocabulary; statuses on Home render only through `StatusBadge` and `NotDeterminable`.

Breakdown and ordering: DEC-0223.

- [AC-21] Before any download has run, Home MUST state that no data has been downloaded yet and offer setup.
- [AC-24] Every Home region MUST render each of the eight states as designed or record why one does not apply.
- [AC-25] Every polled region MUST show its last-updated time.
- [AC-26] Home MUST be built from `ui-components` and consume theme tokens only.
- [AC-19] Every user-visible label MUST use the display label STD-UI-1 defines.
- [DAC-E5-1] While `attention.latest_download` is null Home MUST render one `card` with `h2` *No data has been downloaded yet.*, *Set up FactorFlow to name the stocks to follow and start the first download.* and **Start setup** (link to `/setup`), with the header still rendered and no tile or list. (traces to: AC-21)
- [DAC-E5-6] The header MUST render the date as *{Weekday}, {YYYY-MM-DD}* and the market state as *Market closed* on Saturdays, Sundays and weekdays before 08:30 or from 15:00 America/Chicago, and as `coverage-unknown` *Market state not determinable* with *FactorFlow has no trading calendar, so it can't tell a session from a holiday.* inside weekday 08:30 to 15:00, across a DST change. (traces to: AC-24)
- [DAC-E5-10] No element with strategy, paper or live text or role MUST render; the summary row's second and third columns MUST be empty, with no *+ New strategy*, no *next rebalance* and no right-hand header action. (traces to: AC-10)
- [DAC-E5-11] When the attention read fails, the header MUST stay and each card's body MUST be replaced by *Couldn't read {what needs you / the data summary}: {reason}.* with **Try again**, with *checked {time}* aging. (traces to: AC-24)
