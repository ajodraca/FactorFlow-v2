# Home Journey End to End: a Data Problem Appears, Is Fixed and Leaves

## User Story

As an owner-operator, I want capability flow 3 proven against the real product, so that a partial download shows up on Home with its count in the rail, **Fix data** takes me to Data health, and the item leaves once the data is fixed.

## Description

Logical component: `home-ui`. Creates `tests/e2e/home-needs-you.spec.ts` with the journey of `component-design-home-ui.md` §7 against a real API and PostgreSQL container, using the delivered acquisition stack stub to produce a partial download that leaves three stocks failed: Home shows the data item naming them and the Data health chip reads *3*; **Fix data** opens Data health with the three rows; after a clean download the item and the chip are gone. The journey crosses into Data health (E6), hence the dependency on a later epic (DEC-0223).

Breakdown and ordering: DEC-0223.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-9] An item MUST leave the list only when its cause is resolved, never because it was viewed.
- [AC-16] The Data health destination MUST carry the number of followed stocks with problems and the Home destination the number of *Needs you* items.
- [AC-8] Home MUST show how many followed stocks are current out of how many are followed.

### Derived

- [DAC-E5-S4-1] Given a store where a download ended `partial` with failures on *FBXX*, *KO* and *TSLA*, When `/home` opens, Then the *Needs you* card holds an item titled *FBXX, KO and TSLA are missing data*, the rail's Data health item is named *Data health, 3 stocks with problems* and the Home item *Home, 1 item needs you*. (traces to: AC-16, AC-9)
- [DAC-E5-S4-2] Given **Fix data** followed, When Data health opens, Then *Needs fixing · 3* lists the three symbols; When the browser goes back to Home, Then the item is still present. (traces to: AC-9)
- [DAC-E5-S4-3] Given a later download that writes the three stocks' data, When the next attention read answers, Then the item is gone, no chip renders on either destination, and the tile reads *Yes*. (traces to: AC-9, AC-8)
