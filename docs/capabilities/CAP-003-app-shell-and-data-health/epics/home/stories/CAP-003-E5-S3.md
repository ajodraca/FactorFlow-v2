# The *Needs You* Card

## User Story

As an owner-operator, I want a list of what needs me, most important first, each with exactly one action, so that I can act on data problems, a failed download, a missing key or a first download in one step, and see it leave when its cause is gone.

## Description

Logical component: `home-ui`. Creates `web/src/screens/home/needs-you-card.tsx` as `component-design-home-ui.md` §2.5 specifies: the list is `sortAttention(deriveNeedsYou(attention, scores))` from E1-S4, the same call the shell's Home chip makes (AC-16); the header is *Needs you · {n}* with *Most important first. Nothing here is urgent unless marked.* and *checked {time}*; each row is E1-S4's `NeedsYouItemRow` with the catalogue's tag, tier, title, body and single action from `copy.ts` (DEC-0203, DEC-0216, PROVISIONAL). The `first_download` body drops its count clause while `total` is null (DEC-0213 f); `score_failed` drops its second sentence when no set exists. With no item the card reads *Nothing needs you right now.* with *checked {time}*. A changed count is announced politely and focus never moves. `failure_reason` and score `reason` render as text (AGT-PROHIB-003); `credential_present` reaches the screen only as the `credential_missing` item.

Breakdown and ordering: DEC-0223.
