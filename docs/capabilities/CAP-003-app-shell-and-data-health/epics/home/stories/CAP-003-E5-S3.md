# Needs You Card and the Home Screen: One Action per Item, the Honest Empty State and Nothing Unshipped

## User Story
As an owner-operator, I want Home to list what needs me, most important first, each with one action, and to say plainly when nothing does or when no data has been downloaded yet, so that one look tells me whether to act.

## Description
Creates `web/src/screens/home/needs-you-card.tsx` (header *Needs you · {n}*, the sub-line, *checked {time}* right-aligned; a `ul` of `needs-you-item` rows over `sortAttention(deriveNeedsYou(attention, scores))` with the catalogue copy of home-ui 2.5 per kind, plural forms, the `first_download` body dropping its count clause while `total` is null, `score_failed` dropping its second sentence when no set exists, each action a link styled `button` `outline` named for the item; *Nothing needs you right now.* with *checked {time}* when empty; a changed count announced politely with focus never moving; *Couldn't read what needs you: {reason}.* with **Try again** while attention fails) and `web/src/screens/home/index.tsx` (`HomeScreen`: `main` with the date `h1`, the three-column summary row with the tile in the first column and the other two empty, *Needs you* beside it; while `latest_download` is null, one `card` with `h2` *No data has been downloaded yet.*, its sentence and **Start setup** to `/setup`, the header still rendered and no tile or list; no element with strategy, paper or live text or role; capped at `LAYOUT.contentMaxWidth`). Writes `needs-you-card.test.tsx` and `home.test.tsx`.

Source: component-design-home-ui.md 2.1, 2.2, 2.5, 3, 4, 7, 8, 10; epic CAP-003-E5 DAC-E5-1, DAC-E5-7 to DAC-E5-11.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-7] Home MUST show the first download's progress through the *Your first download is running* item until scores exist.
- [AC-9] Every item MUST have exactly one action, items MUST be ordered by severity tier then recency, and an item MUST leave only when its cause is resolved.
- [AC-10] Home MUST render no strategy, paper or live region and no placeholder for one.
- [AC-12] The `download_not_complete` item MUST render *Interrupted* as serious and *Failed* as critical.
- [AC-16] Home's *Needs you* count MUST be the same derivation the rail's Home chip uses.
- [AC-21] Before any download has run, Home MUST state that no data has been downloaded yet and offer setup.
- [AC-24] Every Home region MUST render each of the eight states as designed or record why one does not apply.
- [AC-25] Every Home operation MUST be completable by keyboard; every polled region MUST show its last-updated time.
- [AC-26] Home MUST be built from `ui-components` and consume theme tokens only.
- [DAC-E5-1] The never-downloaded empty state MUST render as stated. (traces to: AC-21)
- [DAC-E5-7] Each item MUST render the catalogue's tag, tier, title, body and single action for its kind, with the stated plural and dropped-clause rules. (traces to: AC-9)
- [DAC-E5-8] Every item action MUST be a link styled `button` `outline` whose accessible name names the item; no action MUST mutate state. (traces to: AC-9, AC-25)
- [DAC-E5-9] With no item the card MUST read *Nothing needs you right now.* with *checked {time}*; a changed count MUST be announced politely and focus MUST never move. (traces to: AC-9, AC-25)
- [DAC-E5-10] No element with strategy, paper or live text or role MUST render; the summary row's second and third columns MUST be empty. (traces to: AC-10)
- [DAC-E5-11] While attention fails each card's body MUST be replaced by its error with **Try again** and *checked {time}* aging; while the summary answers `404` the server items still render and the first-download item follows DEC-0216. (traces to: AC-24)
