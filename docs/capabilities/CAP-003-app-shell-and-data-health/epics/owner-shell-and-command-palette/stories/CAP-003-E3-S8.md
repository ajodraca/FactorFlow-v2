# Register Home with Its Destination and Count Chip

## User Story

As an owner-operator, I want Home in the rail with the number of things that need me, so that the product opens on it after my first download and the rail tells me when something needs attention.

## Description

Logical component: `owner-shell`. Registers `home-ui`'s `HomeScreen` (E5-S1): the `/home` route in `routes.tsx`, the *Home* title in `titles.ts`, and the destination `{ group: "primary", label: "Home", to: "/home", count: "needs-you" }` as the first entry of `DESTINATIONS` (`component-design-owner-shell.md` §2.6). The Home chip, E3-S5's `count-chip.tsx`, now renders `deriveNeedsYou(attention, scores).length` live, the same call `home-ui` makes (DAC-E3-7; AC-16). Extends `shell.test.tsx` with the chip cases over the live destination and `routes.test.tsx` with the route.

Breakdown and ordering: DEC-0223.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-1] The rail MUST list Home first in the primary group.
- [AC-2] After the first download has been started, `/` MUST open Home.
- [AC-16] The Home destination MUST carry the number of *Needs you* items, absent when zero.
- [DAC-E3-2] A destination enters `DESTINATIONS` only in the change that registers its screen. (traces to: AC-1, AC-27)
- [DAC-E3-7] The Home chip MUST equal `deriveNeedsYou(attention, scores).length`; a zero count MUST render no chip; the item's accessible name MUST include the count in words. (traces to: AC-16, AC-25)

### Derived

- [DAC-E3-S8-1] Given attention items yielding four *Needs you* entries, When the rail renders, Then the Home item is named *Home, 4 items need you* and its chip reads *4*; given none, Then it is named *Home* with no chip. (traces to: DAC-E3-7)
- [DAC-E3-S8-2] Given `most_recent_run` set, When `/` renders, Then the location becomes `/home` and `HomeScreen` is in the document with the top bar reading *Home*. (traces to: AC-2)
- [DAC-E3-S8-3] Given `DESTINATIONS` after this story, When read, Then its first entry is Home and the primary group holds Home (and Research when registered) only. (traces to: DAC-E3-2)
- [DAC-E3-S8-4] Given the count changing from 2 to 3 between attention answers, When rendered, Then the rail's polite live region announces the new count once and focus does not move. (traces to: DAC-E3-7)
