# Command Palette: Stocks, Universes and Pages, Every Item Navigating

## User Story
As an owner-operator, I want to type part of a symbol or a page name from anywhere and jump there, so that I never navigate through three screens to reach one.

## Description
Creates `web/src/app/command-palette/index.tsx` (`<CommandPalette open onOpenChange />` on `ui-components`' `command`), `use-stock-search.ts` (debounced 250 ms server search through the delivered `listInstruments({ symbol: prefix, lifecycle: "active", limit: 8 })`, aborted with `AbortController` on new text), `universes.ts` (`fetchActiveUniverses()`: `GET /api/universes?lifecycle=active` through the exported `requestJson`, once per open, only while `RESEARCH_REGISTERED`), `pages.ts` (the shipped `DESTINATIONS` plus *Coverage*, *Followed stocks*, *Downloads*), `targets.ts` (`stockTarget(symbol)`: `/research/stocks/{symbol}` when registered, else `/data/coverage?symbol={symbol}`; `universeTarget(id)`; DEC-0207) and `copy.ts`, with the states of command-palette 2.4 and the tests of 2.1 (command-palette 7). The shell's listener and opener mount it in E3-S6; the e2e keyboard journey is E3-S8.

Source: component-design-command-palette.md 2.1 to 2.4, 3, 4, 5, 7; epic CAP-003-E3 DAC-E3-11, DAC-E3-12.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-22] The owner MUST be able to find followed stocks, universes and pages from the palette; it MUST NOT offer any action that places or stops trading.
- [AC-24] The palette's eight states MUST render as designed or record why one does not apply.
- [AC-27] A stock MUST open the Research evidence page when its routes are registered.
- [DAC-E3-11] The palette MUST show Stocks, Universes (only while research routes are registered) and Pages in that order, with no Actions group, and the stock target per registration. (traces to: AC-22, AC-27)
- [DAC-E3-12] The palette MUST render the hint row before typing, `CommandEmpty` *No stocks or pages match "{text}".*, the *Showing the first 8. Keep typing to narrow.* row when `next_cursor` is set, and per-group errors that leave the other groups usable; while health is unreachable it still opens and Pages stays usable. (traces to: AC-24)

### Derived
- [DAC-E3-S5-1] Given typed text *K* then *KO* within 250 ms, When the search fires, Then one request with `symbol=KO&lifecycle=active&limit=8` is sent and the earlier one, if in flight, is aborted so a stale answer never overwrites a newer one. (traces to: DAC-E3-11)
- [DAC-E3-S5-2] Given `RESEARCH_REGISTERED` false, When the palette opens, Then no universes request is sent and no Universes group renders; given it true, Then one request per open and the group filtered locally. (traces to: DAC-E3-11)
- [DAC-E3-S5-3] Given `Esc` or an item chosen, When the dialog closes, Then focus returns to the element focused before it opened and nothing typed is kept (command-palette 4). (traces to: AC-25)
- [DAC-E3-S5-4] Given the AC-26 literal-scan test `web/src/components/token-literals.test.ts` (CAP-003-E1-S1), When this story adds `web/src/app/command-palette/` to its scanned directories, Then every `.ts` and `.tsx` source under it, test files excluded, contains no spacing, size or colour literal (`px`, `rem`, `em`, `vh`, `vw`, hex, `rgb(`, `hsl(`) outside `theme.css` tokens and `layout.ts`, and the test passes. (traces to: AC-26)
- [DAC-E3-S5-5] Given the palette's groups, rows, hint, empty and error states rendered in every state this story defines, When its visible text and accessible names are scanned for *instrument*, *acquisition*, *acquire*, *run*, *runs*, *Retire*, *Retired*, *Provider credential* as whole words in any case (the DAC-E7-3 term list), Then none appears, and every label is the STD-UI-1 v6 display label from `labelOf` or this component's `copy.ts`, never the domain term beside it. (traces to: AC-19)
- [DAC-E3-S5-6] Given no status is rendered in the palette (its rows are symbols, universe names and page names), so the one-tier rule applies vacuously and is recorded as not applicable; stale and unavailable states are not applicable per command-palette 2.4, When rendered, Then each goes through `StatusBadge` with its label as text and its tier shape `aria-hidden`, a value no artifact can determine goes through `NotDeterminable`, and no state is conveyed by colour alone. (traces to: AC-20)

## Technical Details

### API Contract
- Consumes `GET /api/instruments?symbol=&lifecycle=active&limit=8` (delivered `listInstruments`) and `GET /api/universes?lifecycle=active` as CAP-002 publishes it (assumed filter, command-palette 14.1; filtered locally otherwise).

### Data Changes
- None: no schema, migration, index or browser storage.

### Implementation
- Files: `web/src/app/command-palette/index.tsx`, `use-stock-search.ts`, `universes.ts`, `pages.ts`, `targets.ts`, `copy.ts`, `command-palette.test.tsx`, `use-stock-search.test.ts`.
- `shouldFilter={false}` on the Stocks group; `loop` set; dialog labelled *Search FactorFlow* (command-palette 3).

### Validation
`npm run test`, `npm run lint`, `npm run format`, `npx tsc --noEmit`, `npm run build` (tech stack v7 validation commands).
