### IR-001 — `loading` is never asserted false once health has settled as unreachable

Probe P1 (`HEALTH_UNREACHABLE_AFTER_ANSWER`, both reads answered, `attentionOk(null)`, so `loading` should be `false`) passes at HEAD and fails under the mutant.
- **Expected evidence/behavior**: A test fails when an unreachable health, which is a settled health, holds `loading` true. Sources: T005 (c), T009, and DEC-0344 (*A pending read: its step is not done, and `loading` is `true`*). An unreachable health is not pending.
- **Impact**: Every story test would pass with the regression, and setup would show its skeleton for as long as health stays unreachable. It is not visible yet. - **Required remediation**: Add an assertion that `loading` is `false` with health `unreachable`, both reads answered and attention `ok`. It must fail under `loading-health-not-answering`.
