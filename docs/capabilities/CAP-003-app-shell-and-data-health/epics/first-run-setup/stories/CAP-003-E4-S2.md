# Setup Steps 1 and 2: the Step List, the Step Card, Market Data Key Presence and History Depth

## User Story
As an owner-operator, I want setup to tell me whether my market data key was found and to save how much history to keep, so that the first two things the product needs are settled before I name stocks.

## Description
Creates `web/src/screens/setup/step-list.tsx` (`stepper` `vertical` as a `nav` *Setup steps* with `aria-current="step"`, done steps as links and said so in text), `step-card.tsx` (a `section` labelled by its `h2`, which takes focus when the step changes; UX design §3), `step-market-data.tsx` (step 1: `badge` `status-good` *Found* or `status-critical` *Missing* from `health.credential_present`, the variable name and restart line when missing, `coverage-unknown` *Not determinable* with its reason while health is unreachable, **Continue** always available) and `step-history-depth.tsx` (step 2: `form` with `input` `numeric` with the years suffix, `PUT /api/settings/history-depth` through the delivered `setHistoryDepth`, a `422` rendered as the field error *History depth must be a whole number of years from 1 to 50.* with the value kept, the plan-limit note as copy), with tests (setup-ui 2.1, 2.3, 10).

Source: component-design-setup-ui.md 2.1, 2.3, 4, 7, 10; epic CAP-003-E4 DAC-E4-3, DAC-E4-4, DAC-E4-13.
