# First-Run and *Add Later* Journeys End to End

## User Story

As an owner-operator, I want the whole first run proven against the real product, from an empty install to a running download and Home, and the *Add later* exit proven to leave setup incomplete with my drafts kept, so that capability flow 1 works as one operation.

## Description

Logical component: `setup-ui`. Creates `tests/e2e/setup-first-run.spec.ts` with the two Playwright journeys of `component-design-setup-ui.md` §7 against a real API and PostgreSQL container, as the delivered e2e suite runs: (1) an empty install opens setup; all four steps are completed by keyboard; after **Start download** `/` opens Home with the first-download item; (2) *Add later* and **Continue** reach step 4 blocked; **Go to Home** lands on Home's empty state and `/` still opens setup with the drafts kept; **Manage followed stocks** opens `/data/followed`; after following a stock there and returning, step 4 is ready; `/` opens Home only after a download is started. The journeys cross into Home (E5) and the followed-stocks screen (E7), which is why this story depends on stories in later epics (DEC-0223).

Breakdown and ordering: DEC-0223.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-2] Until the first download has been started, `/` MUST open setup; afterwards Home.
- [AC-3] Going back MUST keep every value entered in later steps.
- [AC-7] The owner MUST be able to start the first download from setup and leave; Home MUST then show its progress.
- [AC-21] After *Add later*, **Go to Home** MUST land on Home's honest empty state.
- [AC-25] Every setup operation MUST be completable by keyboard.

### Derived

- [DAC-E4-S6-1] Given an empty store and the key set, When the browser opens `/`, Then the URL becomes `/setup` with step 1 current; When `Tab` and `Enter` alone complete steps 1 to 3 with twelve pasted symbols and **Start download**, Then a `progressbar` renders in step 4 and `/` thereafter opens `/home` showing *Your first download is running*. (traces to: AC-2, AC-7, AC-25)
- [DAC-E4-S6-2] Given step 2 filled with *7* and step 3 with a paste, When **← Back** returns to step 2 and **Continue** moves forward again, Then the paste is still in the textarea. (traces to: AC-3)
- [DAC-E4-S6-3] Given *Add later* and **Continue** on an install with no stocks, When step 4 renders, Then **Start download** is blocked; When **Go to Home** is followed, Then Home reads *No data has been downloaded yet.*; When `/` is opened, Then it lands on `/setup` with the years text still in the draft. (traces to: AC-21, AC-2)
- [DAC-E4-S6-4] Given **Manage followed stocks** followed and one stock followed on `/data/followed`, When the owner returns to `/setup`, Then step 3 is done and step 4's **Start download** is enabled. (traces to: AC-3)
