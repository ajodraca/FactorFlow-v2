# First-Run Journey End to End: Setup by Keyboard, Start Download, Add Later and Return

## User Story
As an owner-operator, I want the first run proven against the running product, so that an empty install reaches its first download, or leaves setup honestly, exactly as designed.

## Description
Writes `tests/e2e/setup-first-run.spec.ts` (setup-ui 2.1, 7): an empty install opens setup; all four steps by keyboard; after **Start download** the URL `/` redirects to `/home`; *Add later* and **Continue** reach step 4 blocked; **Go to Home** navigates to `/home` and `/` still opens setup with the drafts kept; **Manage followed stocks** opens `/data/followed`, and after following a stock there and returning, step 4 is ready; `/` redirects to `/home` only after a download is started. The assertions on Home's content (its empty state, the first-download item) belong to E5-S4, which registers and proves Home (backlog review v2 FINDING-2); this spec asserts the `/home` URL.

Scheduled after the E4 closing story CAP-003-E4-S6, which registers `/setup`: the driver orders by dependencies, ties by number, so the numbering keeps the owner-shell registration story as E4's closing story (DEC-0223 answer A) while this journey runs once the route exists.

Source: component-design-setup-ui.md 7; epic CAP-003-E4 NFR *Accessibility*.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC
- [AC-2] Starting the first download from setup MUST make `/` open on Home from then on; until then `/` MUST keep opening setup.
- [AC-3] Going back MUST keep every value entered in later steps.
- [AC-7] The owner MUST be able to start the first download from setup.
- [AC-21] After *Add later*, setup MUST let the owner leave with no download started.
- [AC-25] Every setup operation MUST be completable by keyboard.

### Derived
- [DAC-E4-S5-1] Given the real stack with the Massive stub, When the four steps are completed by keyboard alone, Then `POST /api/acquisition-runs` is accepted and the progress region shows *checked {time}* advancing. (traces to: AC-7, AC-25)
- [DAC-E4-S5-2] Given *Add later*, When **Go to Home** is activated and the owner returns to `/setup`, Then the years text and the radio choice are as left, and `/` still lands on `/setup`. (traces to: AC-21, AC-3)
