# Save-as-Universe and Add-to-Universe Dialogs

## User Story

As an owner-operator, I want to save a reviewed result as a universe or add checked stocks to one, so that a result I have studied becomes a universe in one step.

## Description

Delivers `web/src/screens/research/save-as-universe-dialog.tsx` and `add-to-universe-dialog.tsx`. Save is offered only under All followed stocks, is `blocked` at zero matches and posts the same thresholds, `hide_incomplete`, search prefix and `setId` the results header counted. `classification_set_changed` swaps Save for Review new result; `universe_name_in_use` attaches to the field. Add lists active universes plus New universe.

Source: `component-design-classification-ui.md` sections 2.7, 7; `ux-design.md` section 1.1.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-2] The user MUST be able to save the result of a threshold filter as a named universe, and that universe's membership MUST NOT change afterwards unless the user changes it. (the Save-as-universe dialog this screen hosts)
- [AC-5] The product MUST refuse to create or save a universe with no members, and MUST refuse to remove a universe's last member. (the zero-match blocked state this screen renders)
- [DAC-E4-5] "Save these {n} as a universe…" MUST be blocked at zero matches and, when confirmed, MUST post the same thresholds, `hide_incomplete`, search prefix and set id the results header counted, so the created universe's member count equals that header's count. (traces to: AC-2, AC-5)

### Derived

- [DAC-E4-S8-1] Given zero matches, When Save is shown, Then it is `blocked` with its reason. (traces to: DAC-E4-5)
- [DAC-E4-S8-2] Given a search is active, When saved, Then the request carries the prefix as `symbol` (null otherwise) and the description names the search. (traces to: DAC-E4-5)
- [DAC-E4-S8-3] Given a `201`, When saved, Then the dialog closes and a toast links to the universe. (traces to: AC-2)
- [DAC-E4-S8-4] Given `classification_set_changed`, When received, Then Save is replaced by Review new result. (traces to: AC-2)
- [DAC-E4-S8-5] Given Add, When it succeeds, Then it toasts Added {n} stocks to {name} with the already-member clause; `universe_retired` shows its wording. (traces to: AC-5)
