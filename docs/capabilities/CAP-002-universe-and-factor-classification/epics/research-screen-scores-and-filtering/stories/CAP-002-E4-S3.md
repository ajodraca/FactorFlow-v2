# Factor Cell and Possibly-Restated Mark Patterns

## User Story

As an owner-operator, I want a factor cell that never confuses a measured value with an unmeasured one, so that a number I cannot trust never passes for one I can.

## Description

Delivers `web/src/components/patterns/factor-cell.tsx` and `restated-mark.tsx` (creating the `patterns/` directory), with tests beside them. The four renderings are a percentile with `aria-hidden` bar; `coverage-absent` Incomplete with the reason tooltip; `coverage-unknown` Not enough to rank; `status-neutral` Not followed. The mark reads Possibly restated, with the glyph `aria-hidden` (DEC-0075). Shared by Research, universe members, Compare and Stock evidence.

Source: `component-design-classification-ui.md` sections 2.1, 2.5, 7; `ux-design.md` section 3.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-9] Every classified factor MUST be shown as a standardised score together with a percentile rank from 0 to 100. (display side)
- [AC-12] The product MUST NOT show a score or percentile on a factor for a stock unless every input that factor needs is present and current, and MUST instead show the stock as not classified on that factor with the missing or outdated input named.
- [AC-14] When fewer than 30 stocks qualify on a factor, the product MUST NOT show scores or percentiles on that factor, and MUST state that there are not enough stocks to rank and how many qualified.
- [DAC-E4-1] A scored factor cell MUST show a whole-number percentile and a bar; an incomplete factor MUST show "Incomplete" and name the input that fell short; a factor below 30 qualifying stocks MUST show "Not enough to rank" in every cell of that column with the count stated once in the header. (traces to: AC-9, AC-12, AC-14)

### Derived

- [DAC-E4-S3-1] Given an unscored factor, When rendered, Then it never shows `0` or a bare number, only the word, shape and token for its state. (traces to: DAC-E4-1)
- [DAC-E4-S3-2] Given a measured `0.00` standardised score, When rendered, Then it appears as `0.00`. (traces to: AC-9)
- [DAC-E4-S3-3] Given `restatedPossible` on value or growth, When rendered, Then the mark's accessible name and text are Possibly restated, and it never renders on momentum. (traces to: AC-12)
- [DAC-E4-S3-4] Given a status, When rendered, Then no polarity colour carries a value and every status has a word plus a shape or pattern (STD-UI-4, STD-UI-14). (traces to: AC-14)
