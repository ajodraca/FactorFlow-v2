# Filters Pane and Threshold Sentences

## User Story

As an owner-operator, I want to filter by factor thresholds, hide incomplete stocks and search by symbol, so that I can narrow the list in plain sentences.

## Description

Delivers `web/src/screens/research/filters-pane.tsx` (Find a stock, Look in, one threshold sentence per factor, Hide incomplete, Clear filters) and `threshold-sentence.tsx` (blueprint section 4.7 builder). Every change is a request and updates the URL; Clear filters resets all of them and keeps the sort. On universe detail the pane has no Look in.

Source: `component-design-classification-ui.md` sections 2.4, 2.5, 7; `ux-design.md` section 1.1.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-16] The user MUST be able to sort stocks by any factor's score or percentile, filter them with thresholds on one or more factors at once, and view chosen stocks side by side, both across all classified stocks and within a single universe. (the sort, filter and selection controls)
- [DAC-E4-3] The results heading MUST read the server's `match_count`, never the number of rows loaded into the table, and sort, thresholds, scope, hide-incomplete and search MUST survive a reload and back navigation because they live in the URL. (traces to: AC-16)

### Derived

- [DAC-E4-S5-1] Given a percentile of 101 or a non-finite standardised score, When the field blurs, Then it is a field error before any request; a blank value means no threshold. (traces to: AC-16)
- [DAC-E4-S5-2] Given a threshold, scope, hide-incomplete or search change, When made, Then exactly one list request is issued with the mapped parameters and the URL updates. (traces to: DAC-E4-3)
- [DAC-E4-S5-3] Given Clear filters, When activated, Then all filters reset and the sort is kept. (traces to: DAC-E4-3)
- [DAC-E4-S5-4] Given each sentence, When read by assistive technology, Then its accessible name reads as the blanks of the sentence. (traces to: AC-16)
