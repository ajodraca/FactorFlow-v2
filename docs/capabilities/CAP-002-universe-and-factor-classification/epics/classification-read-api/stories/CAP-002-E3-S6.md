# API Composition: Scheduler Start in the Lifespan and No-Secrets Test over the New Routes

## User Story

As an owner-operator, I want the classification scheduler started with the application and the no-credential guarantee extended over the new routes, so that classifications refresh automatically and the new surface leaks no secret.

## Description

Edits the two delivered files this EPIC's API side still owns: `src/factorflow/api/app.py` (`_lifespan` creates the classification task from `ClassificationSettings()` beside the reclaim task and cancels both on shutdown; imports `run_classification_loop` and `ClassificationSettings`) and `tests/unit/test_api_no_secrets.py` (the same no-credential assertion over the universes and classifications routes). The two `include_router` calls are made by CAP-002-E1-S6 and CAP-002-E3-S5 (DEC-0086); the end state of `app.py` is what DAC-E3-13 describes.

Source: `component-design-classification-api.md` sections 2.3, 4, 7.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-10] Classifications MUST be brought up to date without user action after every acquisition run that ends as succeeded or partial, and MUST NOT be recomputed after a run that ends as failed, cancelled or abandoned. (start side: the lifespan task that runs E2's scheduler loop; the loop itself and what it does are E2's)
- [AC-16] The user MUST be able to sort stocks by any factor's score or percentile, filter them with thresholds on one or more factors at once, and view chosen stocks side by side, both across all classified stocks and within a single universe.
- [DAC-E3-13] `create_app` MUST include the `universes` and `classifications` routers before the Host/Origin and request-id middleware and the static mount are added, and `_lifespan` MUST create the classification scheduler task from `ClassificationSettings()` beside the reclaim task and cancel both on shutdown; `tests/unit/test_api_no_secrets.py` MUST carry its no-credential assertion over the new routes; no other delivered API file changes. (traces to: AC-10, AC-16)

### Derived

- [DAC-E3-S6-1] Given the lifespan, When the app starts, Then the classification task is created beside the reclaim task and both are cancelled on shutdown, with `CancelledError` swallowed as for the reclaim task. (traces to: AC-10)
- [DAC-E3-S6-2] Given `test_api_classification_lifespan.py` with injected doubles, When it runs, Then the scheduler coroutine is called with the pool and `ClassificationSettings()`. (traces to: AC-10)
- [DAC-E3-S6-3] Given any universes or classifications route, When the no-secrets test runs, Then no response or log contains a credential. (traces to: DAC-E3-13)
- [DAC-E3-S6-4] Given the edit, When `git diff` is read, Then no delivered file other than `app.py` and `test_api_no_secrets.py` changed and no existing line is removed or reordered (AGT-SCOPE-002). (traces to: DAC-E3-13)
