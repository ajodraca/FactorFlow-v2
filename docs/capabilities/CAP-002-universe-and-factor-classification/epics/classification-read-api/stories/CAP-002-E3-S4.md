# Stock History, Set List and Single-Set Reads with the 3000-Stock Volume Test

## User Story

As an owner-operator, I want a stock's earlier classifications and the history of sets, so that I can see how a result changed and which download it came from.

## Description

Adds `stock_history`, `list_sets` and `get_set` with `sql/stock_history.sql` and `sql/sets.sql`, and `tests/integration/test_reader_volume.py` (3000 stocks, `slow`) covering list, sort, count and compare at volume.

Source: `component-design-classification-reader.md` sections 2.6, 5, 7.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-18] Every classification MUST be retained with the date it was produced and MUST NOT be overwritten, and the user MUST be able to see a stock's earlier classifications.
- [AC-23] A value or growth classification MUST be marked as possibly reflecting restated data when any fundamental behind it was acquired as historical backfill, for a period already reported before acquisition of that stock began, and the mark MUST be retained with that classification in its history. (read-through side)
- [DAC-E3-9] A stock's history read MUST return only `complete` sets' results, newest first, exactly as each was recorded. (traces to: AC-18)
- [DAC-E3-12] The restatement mark MUST be carried on every read that returns a factor cell: list, compare, evidence and history. (traces to: AC-23)

### Derived

- [DAC-E3-S4-1] Given a stock, When history is read, Then only `complete` sets' results are returned, newest first, exactly as recorded, with the restatement mark each carried. (traces to: DAC-E3-9)
- [DAC-E3-S4-2] Given a stock never classified, When history is read, Then it returns an empty list distinct from an unknown symbol. (traces to: AC-18)
- [DAC-E3-S4-3] Given a `failed` or `building` set, When history or sets are listed, Then history excludes it and the set list includes it with its state and `failure_reason`. (traces to: DAC-E3-9)
- [DAC-E3-S4-4] Given 3000 stocks, When the list, sort and count run, Then each is served from indexed set rows within the test's budget. (traces to: AC-18)
