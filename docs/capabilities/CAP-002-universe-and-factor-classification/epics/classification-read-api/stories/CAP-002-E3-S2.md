# Classification List Read and the Single evaluate_filter Predicate

## User Story

As an owner-operator, I want a sorted, filtered, searched list of scored stocks over all followed stocks or one universe, counted over the whole result, so that the Research screen and a saved universe agree on what matched.

## Description

Adds to `reader.py` `list_classifications`, `evaluate_filter` and the `Thresholds`, filter and sort models, plus `sql/list_classifications.sql` (matched CTE, `match_count`, page). `evaluate_filter` is defined once and covers the twelve bounds, `hide_incomplete` and the symbol prefix identically for the list, compare and `universe-service`'s snapshot. `sort` resolves through a fixed allowlist of column expressions (SEC-INP-002). A universe scope imports E1's `membership_as_of.sql` rather than restating it (SA-DUP-001).

Source: `component-design-classification-reader.md` sections 2.3, 2.5, 7.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-9] Every classified factor MUST be shown as a standardised score together with a percentile rank from 0 to 100. (serve side: the read this EPIC returns)
- [AC-16] The user MUST be able to sort stocks by any factor's score or percentile, filter them with thresholds on one or more factors at once, and view chosen stocks side by side, both across all classified stocks and within a single universe.
- [AC-23] A value or growth classification MUST be marked as possibly reflecting restated data when any fundamental behind it was acquired as historical backfill, for a period already reported before acquisition of that stock began, and the mark MUST be retained with that classification in its history. (read-through side)
- [DAC-E3-2] `evaluate_filter` MUST be the one predicate used by the list read, by compare, and by `universe-service`'s filter snapshot, covering the twelve threshold bounds, `hide_incomplete` and the symbol prefix identically for all three callers. (traces to: AC-16)
- [DAC-E3-3] A threshold on a factor MUST exclude only a stock classified on that factor that fails the bound; a stock incomplete or unranked on that factor MUST stay listed and counted. (traces to: AC-12 via the shared predicate, AC-16)
- [DAC-E3-4] `hide_incomplete` MUST exclude a stock only when its `not_classified` reason on any factor is `input_missing`, `input_outdated` or `input_not_computable`, never `not_enough_stocks` and never `retired`. (traces to: AC-14, AC-15 via the shared predicate)
- [DAC-E3-5] The unscoped list MUST be active instruments only; a universe scope or a compare request MUST keep retired members, rendered with their `retired` reason. (traces to: AC-15, AC-16)
- [DAC-E3-6] `match_count` MUST be the count over the whole filtered scope (lifecycle scope, thresholds, search, `hide_incomplete`), computed once per request and identical on every page of the same query. (traces to: AC-16)
- [DAC-E3-12] The restatement mark MUST be carried on every read that returns a factor cell: list, compare, evidence and history. (traces to: AC-23)

### Derived

- [DAC-E3-S2-1] Given a threshold on a factor, When the list is filtered, Then only a stock classified on that factor and failing the bound is excluded; incomplete or unranked stocks stay listed and counted. (traces to: DAC-E3-3)
- [DAC-E3-S2-2] Given `hide_incomplete`, When applied, Then a stock is hidden only when its `not_classified` reason on any factor is `input_missing`, `input_outdated` or `input_not_computable`, never `not_enough_stocks` or `retired`. (traces to: DAC-E3-4)
- [DAC-E3-S2-3] Given the unscoped list, When read, Then it holds active instruments only; a universe scope keeps retired members rendered with their `retired` reason. (traces to: DAC-E3-5)
- [DAC-E3-S2-4] Given a multi-page result, When each page is requested, Then `match_count` is identical on every page and counts the whole filtered scope. (traces to: DAC-E3-6)
- [DAC-E3-S2-5] Given a `sort` value outside the allowlist, When validated, Then it is rejected and never interpolated into SQL; the cursor round-trips and rejects a tampered value. (traces to: AC-16)
- [DAC-E3-S2-6] Given a restated value or growth cell, When listed, Then `restated_possible` is on the cell. (traces to: DAC-E3-12)
- [DAC-E3-S2-7] Given `Thresholds` with all bounds null and `hide_incomplete` false, When evaluated, Then every stock in scope matches. (traces to: DAC-E3-2)
