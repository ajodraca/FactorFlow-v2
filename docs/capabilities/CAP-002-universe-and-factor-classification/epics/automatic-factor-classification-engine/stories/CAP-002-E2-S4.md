# Momentum Inputs with Split and Dividend Adjustment

## User Story

As an owner-operator, I want 3, 6 and 12 month returns derived from unadjusted bars with split and dividend adjustment at read time, so that momentum classifications are comparable across corporate actions.

## Description

Adds `sql/momentum_inputs.sql`, the momentum price-currency rule and the momentum stage in `engine.build`. E is the latest bar on or before the classification date minus one month; S_k the latest on or before E minus k months. Bars are stored unadjusted; split factors and dividends are applied here (DEC-0001, DEC-0055 (4)).

Source: `component-design-factor-engine.md` sections 2.4, 7.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-7] Every value, growth and momentum classification MUST be computed from exactly the inputs, periods and equal weights defined for that factor in Section 2.
- [AC-13] An input MUST be treated as outdated when it is a fundamental whose latest reported period ended more than 6 months before the classification date, or a price that is not from the latest trading day the product holds.
- [DAC-E2-1] Each of the eight named inputs MUST be derived exactly per the trailing-twelve-month sums, prior-year comparison, most-recent balance sheet, and read-time split-and-dividend adjustment of unadjusted bars this capability's factor definitions and the system design fix, with no step the capability does not define. (traces to: AC-7)
- [DAC-E2-6] A fundamental input MUST be `outdated` when its latest reported period ended more than 6 months before the classification date; a price-dependent input MUST be `outdated` when the stock's latest bar precedes the latest trading day held across active instruments. (traces to: AC-13)

### Derived

- [DAC-E2-S4-1] Given a stock lacking a bar before S_12, When inputs are derived, Then `return_12m` is `missing` and the other two are present. (traces to: DAC-E2-1)
- [DAC-E2-S4-2] Given a 2-for-1 split inside the window, When the return is computed, Then pre-split prices are halved and the return equals the unsplit series' return. (traces to: DAC-E2-1)
- [DAC-E2-S4-3] Given one dividend of 1 against a prior close of 100, When the return is computed, Then the return factor is multiplied by 1.01. (traces to: DAC-E2-1)
- [DAC-E2-S4-4] Given the bars and actions used, When the input is written, Then `known_on` equals the maximum `observed_on` over them. (traces to: AC-7)
- [DAC-E2-S4-5] Given a stock whose latest bar precedes the latest trading day held, When momentum is decided, Then all three momentum inputs are `outdated`. (traces to: DAC-E2-6)
