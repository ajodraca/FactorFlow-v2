# Deterministic Value Hashing

## User Story

As the observation writer, I want a hash that is identical for identical values across processes and runs, so that re-running acquisition writes nothing when the provider returns what we already hold.

## Description

Delivers `src/factorflow/ingestion/hashing.py`.

Module: `observation-writer`. Small and load-bearing: AC-6's idempotence is exactly this function's determinism. A hash that varies for equal values would duplicate history on every re-run; one that collides for different values would silently drop a restatement.

Source: `component-design-observation-writer.md` section 2.3.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-6] Given a value already held, When it is hashed again in another process, Then the digest is identical so the insert conflicts and writes nothing.
- [DAC-E4-3] Given a value, When it is hashed, Then the canonical form is JSON with sorted keys, no whitespace and decimals rendered as strings, digested with SHA-256.

### Derived

- [DAC-E4-S2-1] Given two dictionaries with the same pairs in different insertion order, When each is hashed, Then the digests are equal, because keys are sorted. (traces to: DAC-E4-3)
- [DAC-E4-S2-2] Given a `Decimal` value, When it is canonicalised, Then it renders as a string, so no float repr enters the digest and `1.10` stays distinct from `1.1` only if the provider distinguishes them. (traces to: DAC-E4-3)
- [DAC-E4-S2-3] Given a value containing a type the canonicaliser does not support, When it is hashed, Then it raises rather than silently coercing, since a wrong digest is worse than a failed write. (traces to: AC-6)
- [DAC-E4-S2-4] Given the digest, When it is returned, Then it is 32 raw bytes, matching the column's length check constraint. (traces to: DAC-E4-S1-4)
- [DAC-E4-S2-5] Given a value differing in any field, When it is hashed, Then the digest differs, so a restatement is always recorded as new. (traces to: AC-5)

## Technical Details

### Implementation

```python
def canonical_json(value: dict[str, Any]) -> bytes:
    return json.dumps(
        value, sort_keys=True, separators=(",", ":"),
        default=lambda i: str(i) if isinstance(i, Decimal) else _unsupported(i),
    ).encode("utf-8")

def value_hash(value: dict[str, Any]) -> bytes:
    return hashlib.sha256(canonical_json(value)).digest()
```

### Testing

- `pytest`, marked `not postgres`. Pure functions, no container needed.
- Key-order independence asserted directly.
- A `Decimal` renders as a string; a `float` input raises.
- An unsupported type raises rather than coercing.
- Digest length is 32 bytes.
- A property test over generated dictionaries asserts equal inputs hash equal and unequal inputs hash unequal.
