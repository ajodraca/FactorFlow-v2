# Runtime Configuration and Credential Loading From the Environment

## User Story

As an owner-operator, I want configuration and my provider credential read from the environment at start, so that no secret is ever committed to the repository and a missing setting fails loudly.

## Description

Delivers `src/factorflow/config/settings.py` and `src/factorflow/config/redaction.py`. Both containers load configuration through this module; the application reads only whether the credential is set, while ingestion uses its value.

Module: `runtime-config`. Pydantic settings models validate at start, so a misconfiguration fails the process rather than surfacing later as a confusing runtime error.

Source: `component-design-runtime-config.md` sections 2.2b, 4; system design 5.12.

## Acceptance Criteria (Given/When/Then)

### From Capability / EPIC

- [AC-13] Given a running process, When configuration is loaded, Then the provider credential comes from the environment and appears in no repository file, no log record, and no API response.
- [AC-14] Given the API process, When it binds, Then it binds to the loopback interface only.
- [DAC-E1-7] Given a required value missing from the environment, When the process starts, Then it fails with a message naming the variable but never its value.
- [DAC-E1-8] Given the credential in memory, When any log record is emitted, Then the credential is redacted.
- [DAC-E1-9] Given the application process, When it reads the credential setting, Then it reads only whether it is set, never the value.
- [DAC-E1-10] Given a rotated credential, When ingestion claims its next run, Then it re-reads the value and rebuilds its provider client without a restart.

### Derived

- [DAC-E1-S3-1] Given a Pydantic settings model, When the environment is loaded, Then every required field is validated at start and a type error fails the process. (traces to: DAC-E1-7)
- [DAC-E1-S3-2] Given a credential value, When it is held, Then it uses a secret-wrapping type whose `repr` and `str` do not expose the value, so an accidental interpolation cannot leak it. (traces to: DAC-E1-8)
- [DAC-E1-S3-3] Given the logging configuration, When it is installed, Then a redaction filter removes any configured secret value from every record, including records emitted by third-party libraries. (traces to: DAC-E1-8)
- [DAC-E1-S3-4] Given the bind address setting, When it is defaulted, Then it defaults to `127.0.0.1` and a non-loopback value is rejected at start rather than accepted silently. (traces to: AC-14)
- [DAC-E1-S3-5] Given the application process, When health reports credential presence, Then it reports a boolean derived from whether the variable is set, and the value is never read into the API's response path. (traces to: DAC-E1-9)
- [DAC-E1-S3-6] Given ingestion holding a provider client, When it claims a run and the credential has changed, Then it rebuilds the client, because claim time is the only point at which no provider connection and no partial instrument write is in flight. (traces to: DAC-E1-10)

## Technical Details

### Configuration Surface

| Variable | Consumer | Required | Notes |
|---|---|---|---|
| `FACTORFLOW_DATABASE_URL` | both | yes | Password never logged |
| `FACTORFLOW_MASSIVE_API_KEY` | ingestion (value), application (presence) | yes | Secret-wrapped |
| `FACTORFLOW_BIND_HOST` | application | no | Defaults `127.0.0.1`; non-loopback rejected |
| `FACTORFLOW_RATE_BUDGET` | ingestion | no | Provider request budget, consumed by CAP-001-E3-S4 |
| `FACTORFLOW_ATTEMPT_LIMIT` | ingestion | no | Default 3, owner decision 2026-09-04 |
| `FACTORFLOW_HEARTBEAT_STALE_SECONDS` | application | no | Reclaim window, consumed by CAP-001-E5-S4 |

Exact names are this story's to fix; the table is the set the designs require.

### Testing

- `pytest`, no container needed, marked `not postgres`.
- A missing required variable raises at start with the variable name present and the value absent from the message.
- A test asserts `repr()` and `str()` of the settings object contain no credential value.
- The redaction filter is exercised against a record whose message embeds the credential.
- A non-loopback bind host is rejected.

### Validation

`uv run pytest -m 'not postgres'`, `uv run ruff check .`, `uv run mypy src`.

### Dependencies

None. Other stories consume this module's settings contract and can be developed against it in parallel.
