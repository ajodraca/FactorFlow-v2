The amendments **improve** alignment on the specific point they address, and this is the substantive result of this review.

Before: `CAP-001-E1-S1` stated "A unique index on `symbol` is deliberately **not** added here", while `component-design-market-data-store.md` section 2.3 included `CREATE UNIQUE INDEX idx_instrument_symbol ON instrument (symbol);` in the same migration. After: the story's SQL block is byte-identical to both the design's section 2.3 block and the shipped `migrations/0001_extensions_owner_state.sql` (verified by direct comparison). `CAP-001-E2-S1` states no index is added and explains why. Neither story contradicts the design.

It was found by adversarial implementation review, after the code shipped. That is a gap in this review lane's own coverage, not in the backlog as it now stands.
