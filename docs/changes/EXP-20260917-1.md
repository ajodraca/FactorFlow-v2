# Expedited Change: Isolate static-bundle tests from build output

## Request and Outcome

Make the API static-mount tests deterministic when a prior frontend build has left ignored `index.html` and asset files in `src/factorflow/api/static/`. The no-bundle test must arrange an empty static directory itself and continue to return a bare `404`, while the bundle fixture must continue to serve its controlled SPA and asset content.

Failure impact is low. An incorrect change can make the static-mount test give false confidence or remain order-dependent, but it cannot alter shipped application behavior.
