**`value_inputs.sql`, per input**

| Input | Rows read (`used`) | Missing when | `as_of` | `periods` / `periods_found` |
| --- | --- | --- | --- | --- |
| `book_to_price` | Rank-1 balance sheet (book equity) and rank-1 income statement (shares). No window | No balance sheet, or no income statement | min(BS P1, IS P1) | BS P1 and IS P1 / every BS and IS period |
| `earnings_yield` | Income-statement TTM P1–P4. Shares from the rank-1 row only | No income statement, or no formed window | IS P1 | IS P1–P4 / every IS period |
| `fcf_yield` | Cash-flow TTM P1–P4 (OCF, capex) and rank-1 income statement (shares) | No income statement, or no formed CF window | min(CF P1, IS P1) | CF P1–P4 and IS P1 / every CF and IS period |

This matches the factor-engine v3 §2.4 table, DEC-0295 and DEC-0116 (3). A balance sheet is now required only for `book_to_price`. `amount`'s `WHERE` keeps shares to `period_rank = 1`, so `earnings_yield` does not multiply shares by four. `stmt.ttm_slot` is all-or-nothing per statement type (`statements.sql`). A rank-1 cash-flow row outside a formed window therefore appears in `used` only when `window_quarters = 0`, and that case is already `periods_missing`.

`less_key` handling: absent or JSON `null` gives 0. A plain-decimal number or string is subtracted. Anything else gives NULL, so book equity is `line_item_absent`. This is exactly DEC-0295. `magnitude` applies `abs()` before `sign`, and `less_key` is subtracted after. No item combines the two modifiers (spec review v5 FINDING-36).

Traceability: commit `ae525ff` carries `Decision-Id: DEC-0295`. DEC-0295 exists only as an untracked file in the harness (ER-003).
