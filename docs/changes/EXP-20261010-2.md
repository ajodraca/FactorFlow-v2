# Expedited Change: The ingestion process commits the runs it executes

## Request and Outcome

The owner directed this change on 2026-10-10 to unblock CAP-001-E3-S7. Supervised run `run-20261010T160604Z` stopped S7 at task T016: in TC-INT-027 the run reached the provider stub and then stayed `running`.

Root cause, in code CAP-001-E4-S5 delivered:

- `src/factorflow/ingestion_main.py` opens its connection with `psycopg.connect(db_url)`, which leaves autocommit off.
- The first `claim_next` commits, because its `with connection.transaction():` starts from an idle connection.
- `active_instrument_ids` then runs a bare `SELECT`. With autocommit off, psycopg opens an implicit transaction and leaves it open.
- From then on, every `with connection.transaction():` in the runner, writer and journal is a nested block. psycopg turns a nested block into a `SAVEPOINT`, and leaving it only releases the savepoint. Per-instrument writes, outcomes and `finalise` are never committed, and no other connection sees them.

Outcome: the ingestion process opens its connection with `autocommit=True`. Each `connection.transaction()` block is then a real transaction that commits on exit, and bare reads no longer hold a transaction open. This is the mode psycopg 3 documents for code that marks transactions explicitly with `transaction()`.

The runner tests did not catch this because they read results back on the runner's own connection, which sees its own uncommitted writes.

## Eligibility and Risk

`python3 scripts/classify-lane.py --none` returned `expedited`, with exit 0. Every signal was answered no, so `lane_signals` is empty.

Risk is medium: the change is one argument, but it decides when the ingestion process's writes become durable. If it were wrong, runs would stay unfinished, which is what happens today. Every write path already marks its own boundary with `connection.transaction()`. The writer's docstrings say the caller owns that boundary, and the runner and journal follow it. So autocommit adds no commit point inside any unit of work that is meant to be atomic.
